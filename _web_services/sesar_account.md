## Creating a SESAR account
The preferred method to create a SESAR account is now authenticating through ORCID.

**ORCID Account (Preferred)**
- You can create an ORCID account at [https://orcid.org/](https://orcid.org/) then use it when signing in to [MySESAR](https://app.geosamples.org).
- Make sure to submit your user profile to finalize account setup


**GeoPass Account (to be deprecated)**
- Register for a GeoPass account: [https://geopass.iedadata.org/josso/](https://geopass.iedadata.org/josso/).
- Log into [MySESAR](https://app.geosamples.org) using your Geopass account
- Make sure to submit your user profile to finalize account setup


**Gain access to a SESAR namespace (user code)**

Users can only register or access sample metadata for user codes or namespaces that they own or have permission to access.

#### Option 1

Create your own on the [MySESAR profile page](https://app.geosamples.org/views/my_profile.php)

#### Option 2
Request permissions from another user by providing the geopass login to the granter. The granter can set up his or her user code permission on the user profile page.
