# Create a SESAR Account

## Setting up a SESAR User Account

### Individual Researcher

1. Create an [ORCiD](https://orcid.org/) Account.&#x20;
2. Login to [MySESAR](https://app.geosamples.org/index.php) with your ORCiD.
3. Follow the instructions to complete your MySESAR Account.
4. Create a [SESAR Code](https://app.gitbook.com/s/kuAfextNoBx3BNIgCEWG/sesar-codes).

### Using SESAR with a Team

If you are the lead of a research team and want to share sample registration, metadata editing, and other tasks with your staff or colleagues, you can do so through the following steps to set up a Team. See also [**Using SESAR Teams.**](<README (1).md#using-sesar-with-a-team>)

#### Team Lead or PI

1. Create an [ORCiD](https://orcid.org/) account if they do not have one already.
2. Login to [MySESAR](https://app.geosamples.org/index.php) with their ORCiD and create a personal account.
3. Create a new Team under Workspace.
4. Create a [SESAR Code](accounts-and-access/choose-a-sesar-code.md) for the Team under 'SESAR Codes'.
5. Invite members to your Team under Settings: Team Members using their ORCID or searching by name.
6. Set permission levels for team members after invitation is accepted.

#### All Other Team Members

1. Create an [ORCiD](https://orcid.org/) account if they do not have one already.
2. Login to [MySESAR](https://app.geosamples.org/index.php) with their ORCiD and create personal accounts.
3. Accept the Team Invitation.
4. Create a personal SESAR code only if they plan on registering personal samples.

Once team members have access to the Team group SESAR code, samples can be registered for the lab group from each individual’s MySESAR account. If the PI of the Team changes, the owner of the SESAR code can be updated. See more information under [Using SESAR Teams](accounts-and-access/using-sesar-teams.md).&#x20;
