# Data and Outputs

Researchers and teams can add up to 5 GB per account. Each image has a maximum file size limit of 15 MB. Acceptable formats include, excel worksheets, word documents, powerpoint, .csv, .txt, .pdf, .jpeg, .png, .tiff, .bmp, .gif, zip files, webpage url and other commonly used file formats. &#x20;

1. Navigate to ‘Data & Outputs’ under ‘Samples’ on the left hand panel.
2. Under the Data & Outputs page, there are three options: Publication, Datasets, and Other Resources.&#x20;
3. Click ‘Add’ to add a publication, dataset, or other resource under each section.&#x20;
4. Under ‘Add’ there are two options: ‘DOI Lookup’ and ‘Manual Entry’.
5. For ‘DOI Lookup’ add the DOI and click ‘Save Publication/Dataset/Other Resource’.&#x20;
6. For ‘Manual Entry’, add ‘Title/Label’\*, description, and drag and drop a file or add a file or add a URL link\*. Then click ‘Save Publication/Dataset/Other Resource’.\
   \*Title/Label is required. URL links must be full links.&#x20;
7. If files are added, the ‘Storage (for file uploads)’ will automatically update.&#x20;

You can drag and drop any of the resources you added under Data & Outputs within the three sections as needed.&#x20;
