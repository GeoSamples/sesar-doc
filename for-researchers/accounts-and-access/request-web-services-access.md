# Request API Access

## Accessing SESAR’s API

Previously, request for Web Services was done through an online form that was sent to the curator for approval. Now, you can directly request API access through MySESAR. \
\
If you or your Team will be using SESAR’s API you must have a SESAR account.\
\
Steps are as follows:

1. Create a SESAR account.
2. Login to MySESAR.
3. Select a SESAR Code for your account.
4. Follow the steps listed in our [API documentation](https://docs.geosamples.org/api).
