# Sampling Method

Sampling method is a recommended list, not a closed vocabulary. Use it for how the sample was collected — for example dredging, coring, or a hand sample from outcrop. Prefer a label from this list when one fits. If none does, you can enter a new method.

Leave it blank if you do not know the sampling method. Use **Sampling method description** for extra detail about equipment or procedure.

The web form suggests these labels as you type. Sample registration, batch upload, and other API writes use the **sampling method label**. An existing label is reused; a new label creates a new sampling method.
