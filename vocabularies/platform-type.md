# Platform Type

Platform type is a recommended list, not a closed vocabulary. Use it for the kind of platform used to collect a sample — for example a ship, drill rig, or icebreaker. Prefer a label from this list when one fits. If none does, you can add a new type. For vehicles launched from a platform, see [Launch Type](launch-type.md).

Leave it blank if you do not know the platform type.

The web form is a dropdown of these labels, with an option to add a new type. Sample registration, batch upload, and other API writes use the **platform type label**. An existing label is reused; a new label creates a new platform type.
