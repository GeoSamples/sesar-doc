# Launch Type

Launch type is a controlled list. Use it for the kind of launch used for sampling — for example ROV, HOV, or AUV. It describes the vehicle or device launched from a platform, not the platform itself. For the platform, see [Platform Type](platform-type.md).

Leave it blank if you do not know the launch type. Use **Not Applicable** when a launch type does not apply.

The web form is a dropdown of these labels. Sample registration, batch upload, and other API writes expect the **launch type label** exactly as listed below.

If a term you need is missing, [request a term](request-a-term.md).

| Launch type | Description |
| ----------- | ----------- |
| AUV | Autonomous Underwater Vehicle |
| HOV | Human-Occupied Vehicle |
| missing | expected value not provided |
| Not Applicable | Not Applicable |
| ROV | Remotely-Operated Vehicle |
| Sled | an instrument towed in the water to collect samples or data |
